# 🍴 Recipes Finder Website

This is a **frontend practice project** where I focused on working with **API fetching**.  
The website allows users to search for a meal and displays a variety of recipes related to the search.  
Each recipe comes with an image, and every image is a **clickable hyperlink** that redirects to detailed recipe information.

## 🚀 Features
- Search for any meal or recipe.
- Fetches real-time data using a public API.
- Displays multiple recipe options with images.
- Each image is clickable and links to more details about the recipe.

## 🛠️ Technologies Used
- HTML
- Bootstrap
- CSS  
- JavaScript (Fetch API)  

## 🎯 Purpose
This project was created to **practice frontend development skills** with a focus on:
- Fetching data from APIs
- DOM manipulation
- Building interactive user interfaces
